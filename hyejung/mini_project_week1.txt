본인 업무와 관계 있는 도메인에 대한 RAG 어플리케이션을 만든다. 아래의 가이드라인을 준수한다.

- 데이터를 모으고 ingest하는 과정을 어떻게 처리했는지 의사결정의 근거를 공개하고 설명 : 어떤 문서, API 등등 (청크 사이즈, 청킹 방식 등등)
- 골든 데이터셋을 생성하고 큐레이션하는 과정을 어떻게 처리했는지 의사결정의 근거를 공개하고 설명
: 강사 노트북의 방법을 동일하게 따라할 필요는 없으며 기존 유형을 삭제하거나 다른 유형을 추가해도 무방 (왜 그렇게 했는지? 몇개나? 어떤 유형?)
- 실제 구축된 RAG 어플리케이션의 workflow를 공개하고 왜 그렇게 구성했는지 설명
: 강사가 설명한 RAG 패턴을 동일하게 따라할 필요는 없으며 새로운 패턴을 적용하도 무방
- 구축된 RAG 어플리케이션을 생성된 골든 데이터셋으로 성능 측정하고 그 결과를 설명 (몇번 하겠다도 팀에서 판단해서 진행)
: 강사가 설명한 지표들(예: faithfulness)을 동일하게 따라할 필요는 없으며 커스텀 메트릭이나 새로운 지표를 추가해도 무방
