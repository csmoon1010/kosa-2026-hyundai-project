## 상품 기본정보

판매상품코드(`slitmCd`)는 시스템에서 상품을 식별하는 값입니다. 등록 화면이나 업무 대화에서는 상품번호라고 부르기도 합니다. 이 값을 입력할 때는 코드 문자열을 그대로 사용하고, 숫자로 변환하거나 앞뒤 자릿수를 임의로 바꾸지 않습니다.

상품명은 판매 화면에 노출할 이름으로 입력합니다. 최소구매수량(`minBuyQty`)을 별도로 정하지 않은 상품은 1개부터 구매할 수 있도록 `1`을 사용합니다. 주문단위 최대주문수량(`ordUnitMaxOrdQty`)을 제한하는 경우에는 1 이상의 수량을 입력합니다.

상품 분류는 대분류(`itemLCsfCd`), 중분류(`itemMCsfCd`), 소분류(`itemSCsfCd`), 세분류(`itemDCsfCd`) 순서로 확인합니다. 분류 코드는 각 단계에 등록된 코드를 사용하며, 예를 들어 `37`, `3701`, `370107`, `37010712`와 같은 값은 입력 형식을 보여주는 사례입니다. 사례의 숫자를 실제 상품 코드로 복사하지 말고 상품 마스터에서 해당 상품에 맞는 코드를 확인합니다.

## 판매 기간과 상품 상태

판매 시작일(`sellStrtDt`)과 판매 종료일(`sellEndDt`)은 연월일 8자리로 입력합니다. 예를 들어 2023년 9월 11일은 `20230911`로 작성합니다. 날짜 값에는 구분 기호를 넣지 않습니다.

상품과세여부(`itemTaxnYn`)는 과세 대상이면 `Y`, 비과세 대상이면 `N`으로 입력합니다. 업무 요청에서 “과세 상품” 또는 “과세 대상”이라고 표현한 경우 저장값은 `Y`이며, “비과세” 또는 “비과세 대상”은 `N`입니다. 과세 여부가 확인되지 않으면 임의로 값을 정하지 말고 담당자에게 확인합니다.

## 스토어픽 설정

스토어픽 전용상품 여부는 `storpiupExclItemYn`, 스토어픽 가능 여부는 `storpiupPossYn`에 입력합니다. 상품을 스토어픽 전용으로 등록하면 `storpiupExclItemYn`을 `Y`로 하고 `storpiupPossYn`은 `N`으로 설정합니다. 일반 상품은 전용상품 여부와 실제 픽업 가능 여부를 각각 확인해 입력합니다.

## 입력 전 확인

Canonical 정의에서 코드·수량·날짜 필드의 타입과 필수 선언 여부를 확인합니다. 예시값은 입력 형식을 이해하기 위한 참고이며 기본값이나 허용 코드 목록을 의미하지 않습니다. 분류 코드와 상품 상태가 불명확하거나 서로 맞지 않으면 등록 전에 상품 담당자에게 확인합니다.
